# datascience-analise-e-visualizacao-de-dados
Arquivo de Prática do curso "Data Science: Análise e Visualisação de Dados" da Alura
Nesse repositório constam o arquivo principal com o código comentado de manipulação dos dados realizados ao longo do curso. Além disso, contém os arquivos necessários para carregar e reali-
zar as análise propostas. Ao carregar o arquivo no programa escolhido (jupyter ou collab ou outro) realizar upload dos arquivos .CSV para que o arquivo funcione corretamente.
